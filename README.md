# Cubic Castles Mods

Two ways to mod Cubic Castles: **Cubic Mods** for the Steam version, and the **Cubic Castles Browser Mods** extension for the web version (Chrome/Brave/Edge).

## Cubic Mods (Steam)

A Windows app that adds extra features to the Steam version of Cubic Castles. Start the game, then open Cubic Mods and it attaches to it.

[![Cubic Mods – New Features for Cubic Castles on Steam](https://img.youtube.com/vi/D-NBMWO8xEs/maxresdefault.jpg)](https://youtu.be/D-NBMWO8xEs)

▶️ https://youtu.be/D-NBMWO8xEs

1. Download `cubic-mods-<version>.exe` from the [Releases](../../releases) page and put it anywhere (your Desktop is fine).
2. Start Cubic Castles from Steam.
3. Double-click `cubic-mods.exe`. If Windows SmartScreen pops up, click **More info** → **Run anyway**.

Click **Check for updates** in the app to get newer versions. Hotkeys and tips are on the [Cubic Mods page](https://github.com/CubicTools/cubic-mods).

## Browser extension (web)

How to install the browser extension and a tour of every feature:

[![Cubic Castles Browser Mods – full tutorial](https://img.youtube.com/vi/whrnC4NFEPk/maxresdefault.jpg)](https://youtu.be/whrnC4NFEPk)

▶️ https://youtu.be/whrnC4NFEPk

1. Download `browser-mod-<version>.zip` from the [Releases](../../releases) page.
2. Right-click it → **Extract All** → **Extract**. Keep that folder somewhere permanent; the extension runs from it.
3. Open `chrome://extensions` (or `brave://extensions` / `edge://extensions`) and turn on **Developer mode**.
4. Click **Load unpacked** and pick the extracted folder.
5. Click **Details** on the extension and turn on **Allow User Scripts** so it can update itself.

The extension source is also in the [`browser-mod`](browser-mod) folder of this repo.
